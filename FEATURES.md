# Peusic Feature Roadmap
## Goal: Match Poweramp + Musicolet + OtoMusic core strengths

**Focus: Playing music first.** Offline-first, no ads, no accounts.
UI/UX style (layout & interaction, not colors):
- **Musicolet**: efficient navigation, folders, multi-queue
- **Poweramp**: player controls, queue, EQ depth, gapless
- **OtoMusic**: clean Material library + Now Playing

Keep **Sonic Aurora** visual identity.
